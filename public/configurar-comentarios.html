ELEMENTAL CORP · ISOLADOS

Ativar comentários e curtidas

Esta configuração é feita uma vez pelo dono do projeto no Supabase. Não é necessário informar a senha do banco nem uma chave secreta ao site.

1. Criar as tabelas e permissões

Copie o script abaixo, abra o SQL Editor do seu projeto, cole e clique em Run. Você pode executar novamente: o script não apaga os comentários ou curtidas existentes.

Abrir SQL Editor

2. Permitir participação sem cadastro

No Supabase, vá a Authentication → Sign In / Providers → Anonymous Sign-Ins (em algumas telas, Providers → Anonymous). Ative as entradas anônimas e salve. Isso cria uma identidade técnica quando alguém curte ou comenta, sem pedir cadastro pessoal.

Não é necessário habilitar Google, e-mail ou SMS para esta versão.

3. Conferir e moderar

Os comentários chegam à tabela isolados_comments com approved = false. No Table Editor, revise o texto, altere approved para true e salve para publicar. Para recusar, você pode apagar o comentário pelo painel.

As curtidas ficam em isolados_likes. O site mostra somente o total e a curtida do próprio navegador, sem publicar os identificadores de quem curtiu.

A chave publishable é pública e as permissões ficam no banco. Nunca coloque uma chave secret ou service_role em arquivos do site.
