# Capa do site

Envie a capa aprovada nesta pasta, em JPG, PNG ou WebP, pelo botão **Add file → Upload files** do GitHub e confirme em **Commit changes**. Pode manter o nome original do arquivo: o build encontra a única imagem desta pasta e a usa como capa, sem alterar seus bytes.

Se futuramente adicionar outras imagens, nomeie explicitamente a capa como `capa-isolados.jpg`, `capa-isolados.png` ou `capa-isolados.webp` para identificá-la. Mantenha apenas uma capa explícita. O arquivo `simbolo-isolados.png` é reservado à marca e não é considerado uma capa.
