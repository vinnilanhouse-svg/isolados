Para o autor

Coloque a capa no site.

Use o arquivo original da arte aprovada. A composição será exibida inteira, sem redesenhar a imagem.

  1. Abra o envio de arquivos pelo botão abaixo e entre na sua conta do GitHub, se solicitado.
  2. Escolha a capa no celular ou no computador. Use JPG, PNG ou WebP; pode manter o nome do arquivo.
  3. Confirme em Commit changes, salvando na branch main. A Vercel iniciará a atualização automática.
Enviar capa pelo GitHub → A capa fica salva para todos os visitantes depois do deploy. Esta página apenas orienta o envio; abrir o botão não publica nenhum arquivo.

Depois que o deploy terminar, atualize a página inicial para ver a capa.
